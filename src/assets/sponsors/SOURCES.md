# Where the sponsors' logos came from

Each file here is the company's own artwork, fetched on 2026-11-19. The rule for which version is used: the company's official black logo where it publishes one, and otherwise its official colour logo for light backgrounds. Nothing is redrawn. What is done to a file before it goes in is described in the main README, under Sponsors.
